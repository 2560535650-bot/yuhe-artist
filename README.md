# 雨荷艺术家网站

艺术家雨荷（肖凤莲）的单页官方网站。

## 网站文件

- `index.html`：网站页面
- `yuhe-portrait.jpg`：首页肖像

## 发布到 GitHub Pages

将本仓库发布为公开仓库后，在 GitHub 仓库的 **Settings → Pages** 中选择：

- Source：Deploy from a branch
- Branch：`main`
- Folder：`/(root)`

保存后，GitHub 会提供一个以 `https://用户名.github.io/仓库名/` 形式访问的网址。该 HTTPS 地址可直接写入 NFC 芯片。
